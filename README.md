# Programmieren lernen mit Python - Weiterführende Konzepte

Dieses Projekt enthält die Codebeispiele aus dem iMooX Kurs 
"Programmieren Lernen mit Python: Weiterführende Konzepte".

## Ordnerstruktur

Jeder Ordner enthält den Code einer Lektion (z.B. 'lec_1' für Lektion 1).

## Ausführen des Codes

* Öffne ein Terminal und navigiere zum Ordner der jeweiligen Lektion
* Führe den Python-Code aus: <code>python dateiname.py</code> oder <code>python3 dateiname.py</code>
